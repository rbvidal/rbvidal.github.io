# Ralph Brandao Vidal — Software Engineering for Knowledge Systems

Personal website. Static HTML/CSS/JS, deployed on GitHub Pages.

## Structure

```
├── index.html              # Main site (all sections)
├── projects/               # Case study pages
│   ├── semantic-platform.html
│   ├── workflow-ai.html
│   └── enterprise-search.html
├── assets/
│   ├── css/main.css        # Design system
│   ├── js/main.js          # Scroll, nav, SVG animations
│   └── img/                # Curated image library (73 photos)
│       ├── hero/
│       ├── research/
│       ├── enterprise/
│       ├── startup/
│       ├── projects/
│       └── about/
├── docs/                   # Product requirements
├── robots.txt
└── sitemap.xml
```

## Design

- No build step, no framework, no npm
- Semantic HTML, WCAG AA accessible
- Glass navigation, editorial layouts, full-width photography
- Inline SVG architecture diagrams
- Lighthouse target >95
