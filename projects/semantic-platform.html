PostGIS with Spring Boot

Spring BootPostGISHibernate SpatialDocker

What this is

A sample project showing how to use PostGIS spatial extensions with Spring Boot and Hibernate Spatial. It came out of a real need during a client project: how to find all database entities within a given radius of a geographic coordinate.

The code is available at gitlab.com/rb2000/postgis-sample.

Approach

The project models entities with latitude/longitude fields, then derives a PostGIS Point geometry column from those values. Hibernate Spatial handles the object-relational mapping between Java geometry types and PostGIS columns.

Queries use PostGIS spatial functions — WITHIN to find points inside a circle, DISTANCE to measure between points. These are exposed through JPQL repository methods. The circle itself is constructed programmatically using a radius-in-meters parameter, converted to the coordinate reference system's units.

Stack

Java 8, Spring Boot 2.5, Hibernate Spatial 5.4, PostGIS (via the postgis/postgis Docker image). REST endpoints are documented with OpenAPI/Swagger.

Key learning

The coordinate unit conversion turned out to be the most interesting part. PostGIS works in the units of the spatial reference system (degrees for SRID 4326), but users think in meters. The distance factor (~100,000 for degrees-to-meters at mid-latitudes) needs to be applied when constructing the search circle. Getting this right was essential for meaningful proximity queries.
