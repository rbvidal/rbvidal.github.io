Satellite Image Classification with Transfer Learning

DL4JTransfer LearningVGG16Computer Vision

What this is

A project exploring transfer learning with the DL4J (Deep Learning for Java) library. It classifies satellite images from the UC Merced Land Use dataset into 21 categories — agricultural, airplane, beach, forest, harbor, and so on.

The code is available at gitlab.com/rb2000/satellite-images-classification.

Approach

Training a deep convolutional network from scratch requires large datasets and significant computation. Transfer learning offers a practical alternative: start with a model pre-trained on ImageNet (VGG16, in this case), freeze its lower layers, and replace only the final classification layer with one that outputs 21 classes instead of 1,000.

The pre-trained layers have already learned general visual features — edges, textures, shapes — that transfer well to satellite imagery. Only the classification head needs to learn the new categories. This reduces training time substantially.

Implementation

Built with DL4J. The UC Merced dataset (2,100 images across 21 categories, 256x256 pixels each) is split 80/20 into training and test sets. The VGG16 model (~500 MB) is downloaded automatically on first run. Training runs for 30 epochs with batch size 10.

The pre-trained model is loaded as a ComputationGraph. The TransferLearning.GraphBuilder API removes the original output layer and adds a new OutputLayer with 21 outputs and softmax activation.

Results

After 30 epochs, the model achieves 91% accuracy on the test set. Some categories are harder than others — buildings and dense residential areas are occasionally confused, which makes sense given their visual similarity. Categories with distinctive patterns (forest, beach, airplane) classify near perfectly.
